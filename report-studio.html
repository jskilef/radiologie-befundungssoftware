Connection & templates

Model connection

WebGPU is required. First use downloads the runtime and model from jsDelivr, GitHub and Hugging Face. Model weights may be cached; report text stays in the browser worker. No API key is used.

CPU mode needs no WebGPU. First use downloads runtime and model files; this can be large and slow. Reports stay in the local worker. Small models may struggle with German and structured reports.

For Gemini use https://generativelanguage.googleapis.com/v1beta/models and enter the model ID separately. Other providers must support OpenAI Chat Completions. Start the optional local launcher if direct browser access fails.

Supports OpenAI-compatible Chat Completions APIs. Local servers must allow browser requests from file:// (CORS). No key is required for servers that do not use authentication.

Report templates

Template edits stay in memory when switching templates. Save settings to keep them for next time.

AI prompts

Edit the task instructions for each action. The app adds the required JSON response format and review-note language automatically. Save settings to keep changes.

API modes send reports to the configured endpoint. Browser-local modes process reports on this device. Use de-identified text and an institution-approved service. Saved settings are password-encrypted. AI suggestions require clinical review before use.

About Report Studio
Report Studio · v1.4.0
A local workspace for reviewing and editing radiology report drafts.
Use your own API connection, templates, and prompts. The interface runs locally; report text is sent to the provider you configure. Saved settings are password-encrypted.
AI suggestions require clinical review. Clinical accuracy and legal compliance have not been certified. Use an institution-approved service for patient data.
